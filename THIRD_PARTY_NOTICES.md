RealityCheck is licensed under the GNU General Public License v3.0 (see
[LICENSE](LICENSE)). The Windows release bundles the third-party software
below, each under its own license. All are compatible with GPL-3.0.

The release includes each Python package's license text in
`_internal\<package>-<version>.dist-info\`. proxy_tools ships no license file;
its package metadata declares the MIT license. Source code for every
component is available from the project links below.

## Not bundled

The desktop window uses the Microsoft Edge WebView2 Runtime, and PDF export
uses Microsoft Edge (or Google Chrome). Both are already on Windows 10/11 and
are not included in the release.
